# Tenant Management System

This is the Android Studio project for the BBT3202 Lesson 6 practical.

## Open and run

1. Open the `TenantManagementSystem` folder in Android Studio.
2. Allow Gradle to sync and install any requested SDK/dependencies.
3. Select an emulator or connected Android device.
4. Click **Run**.

The app uses View Binding and Data Binding. Enter a tenant name, phone number, and rent amount, then tap **SAVE**.
